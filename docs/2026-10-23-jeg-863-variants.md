# JEG-863: Rename DDF variants, hide projections duplicate, remove no-projection fallback

**Date:** 2026-10-23
**PR:** #856 (not merged)
**Branch:** fe/JEG-863-variants

## What changed

After JEG-804 made DDF Value = projections only, the old three-version naming
was misleading. This session:

1. Renamed "DDF Projections" to "DDF Value (projections)" in all user-visible
   text (deal read reasons, production sentences, compare label, movers, targets,
   shell.html copy).
2. Hidden `ddf_value_projections` from all pickers via `sameAs: "ddf_value"`
   pattern with `DDF_PICK_KEYS`, `ddfPickKey()`, `pickableSeries()`.
3. Deleted dead disagree reason (pSide !== vSide branch, dead after JEG-804).
4. Removed no-projection fallback (option B, Jeremy 2026-10-23): DDF Value is
   null when no projections exist, in JS engine and Python reference.
5. Updated copy in values footnote, targets footnote, How values, blend tab,
   disagreement card.
