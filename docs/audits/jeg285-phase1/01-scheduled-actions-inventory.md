## STALL / SILENT / INTERVENTION legend

- **STALL** — the workflow can run for the full timeout, exit non-zero, and the failure only surfaces in the Actions UI; no human notification step exists.
- **SILENT** — the workflow can exit 0 while still publishing stale, partial, or absent output. Examples: a scraper step that swallows failure (`|| echo "Scraper failed, using existing data"`), a step that commits nothing when `git diff --cached --quiet`, or `continue-on-error: true` on a step the rest of the pipeline depends on.
- **INTERVENTION** — the workflow depends on a human to dispatch, approve, or clean up before the next run can produce useful output (e.g. a "hold" review the workflow does not resolve).
