## 2026-11-06 - JEG-1539 lane "find": Trade & Waiver Recommendations and Waivers on the live engine

Contract: find.html and waivers.html run the searches the live #find-trade / #find-league / #waivers routes run, on
engine rows, for the reader's league (DDF.league, lane team). No sample data, no second implementation of value math.

What changed
- `app/next/find-engine.js` (DDF.find): per partner, `TradeValueFinder.findTrades` with the available trade charts as
  the acceptance gate (min 1, the live default), both lineup checks on, Advanced minimum bench as `guardrails.minBackups`,
  then `tradeFit` on rows carrying the chart average (the pairing in opportunities.js), `groupTrades` per class. Pickups:
  `TradeValueWaivers.evaluateAll` with the live context (`TradeValueFinder.ui.depthContext / benchWeights`).
  Your valuation = findTrades/tradeFit `ourKey` and the waivers view; Their valuation = tradeFit `marketKey`;
  "Analyst charts" = `chart_avg` over CBS Sports, USA Today, FantasyPros.
- Classes: Natural fit = tradeFit label natural; Partner neutral = not natural and `them.net >= -them.tau`; Force fit =
  the rest (listed only with Fit: Force fits). Unjudged (too few charts) goes to Partner neutral, labelled.
- `app/next/find-page.js`: filters, sections, cards (give alternatives in a select), repeat cap, Show 10/50/200 per
  section, waiver pickups (gain = starter change in your valuation, minimum gain default 2), Build a Trade links via
  `DDF.engine.buildHref`, journey Back/Next (actionbar). Players each side defaults to 1, 2 (live default); 3 takes about
  9 s for 11 partners; 4 runs for one chosen partner only (all partners at 4-for-4 crashed the tab).
- `app/next/waivers-page.js`: entered list in `DDF.state('available')` (sessionStorage `ddf:available`; `ddf:waivers`
  is the See waiver pickups switch and collided with the old list key), best adds board, S12-C Confirm roster move via
  `DDF.league.setMoves` (lane team's moves layer), Undo last move. Example roster and players removed.
- `pipelines/build_root_pages.py`: ROOT_FILES gains the three scripts and `assets/howto/slides`.

Gotchas (durable)
- `build_root_pages.rewrite_links` rewrites `"page.html..."` inside shared scripts and breaks a JS string that uses
  `\"` (it ends the match at the escaped quote). Use single-quoted HTML attributes in JS strings. Guarded in
  `tests/test_build_root_pages.py`.
- After `git checkout -- dist app/trade-value-chart`, run `make sync` again before testing: the committed engine assets
  are stale and every DDF Value reads null ("not yet published for week 7").
- With Your valuation = DDF (Projection based), tradeFit's projections test is skipped (`projKey === ourKey`), so no
  trade can be Natural (engine rule, JEG-1324).
