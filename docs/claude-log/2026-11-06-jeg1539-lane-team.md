## 2026-11-06 - JEG-1539 lane team: DDF.league, team / explore / partners / settings on the live engine

- `app/next/ddf-league.js` (`window.DDF.league`, API in its header) is the one league reader for the workspace pages.
  Read order: link state (a settings-only 'manual' state does not count as a league), `ddf:pasted`, then the active
  `ddf.v2.workspaces` league as source 'saved' (read only). Lineups come from `TradeValueFinder.lineupValue` on engine
  rows; Analyst charts = `withChartAverage(rows, ['cbs','usatoday','fantasypros'])` (engine row values, estimated values
  included, as v2 Find a trade does); Live market = `fantasycalc`.
- Tiers: position = sum(min(v, 1.25 x slot median)) / sum(slot medians) per QB/RB/WR/TE/FLEX/SUPERFLEX slot, medians
  over every rostered team's DDF lineup, an empty slot counts 0; league table = rank thirds of the rostered team count.
  Partner tags on starters: DDF edge at DDF/Analyst >= 1.15; Analyst / Live market premium when that source > DDF.
- Session keys: `ddf:hold` (held player keys, explore), `ddf:skip` (skipped partner team names), `ddf:waivers` ("1"/"0").
- Nav: ddf-league.js sets `DDF.leagueKnown` and calls `DDF.refreshNav()`; site.js `leagueLoaded()` honours it.
- Gotcha: `git checkout -- dist app/trade-value-chart` (needed before each commit) reverts the synced engine assets, so
  pages built afterwards show no DDF values (every `ddf` null). Run `make sync` again after a checkout before any check.
- Checks: `tests.test_team_engine_parity` (12 settings, 0.1 drift guard, nav with/without ddf:pasted).
