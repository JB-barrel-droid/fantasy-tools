**Deviations from the spec (all to be confirmed by Jeremy)**
- Bench at the engine's bench weights (coordinator): verdict = starters in full + weighted bench change; the table shows the weighted bench number, the raw change is in the detail. Spec said unweighted total.
- Value above waivers = projected points per game above the engine's VP-2 waiver line (espn/cbsros/razzball value-above-waivers, averaged over those that price him); dash if none. DDF Value is already floored at the waiver line, so ddf minus line would repeat DDF Value.
- A kicker or defense the league requires is not offered as a drop (spec: always first drop).
- Share link uses `mine=` and `cands=` (the spec reused `roster=`, which Compare uses for the league shape).
- Injury badges read `injury_status` on the engine rows (Sleeper, as of the build): no per-player status JSON is published, so there is no fetch on open. Coverage today: 62 IR, 52 Questionable, 18 Out, 7 PUP, 3 NA, 2 Doubtful of 734 rows.
- Headline text is "+N starter value", or "+N bench value" when the starters do not change; a force pickup and a combo get their own sentences.
- Page heading is a sentence ("Should you pick anyone up?"), like the other tabs; the tab is "Waivers".
