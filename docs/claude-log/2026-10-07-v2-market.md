## 2026-10-07 - v2 Trade targets tab (Figma frames 03 / 04)

Contract: build the v2 "Market disagreement" tab (frames 03 desktop / 04 mobile), framed as
trade targets per Jeremy: sell where a published chart pays more than our value, buy where it
pays less. No value math in v2 beyond per-player differences of engine series. Branch `v2-market`,
not merged.

### What changed
- `app/v2/targets.js` (new, pure): gap = chart value − our value per player per chart, with our
  value = engine `espn` (ESPN DDA) and charts = engine Indexed `usatoday`, `fantasycalc`,
  `fantasypros`, `cbs`. Missing either side gives a null gap plus a reason. Players without our
  value are left out and counted. Older-week charts are skipped unless opted in.
- `app/v2/v2.js` / `shell.html` / `v2.css`: hash route `v2/#trade-targets`, "Trade targets" nav
  item in place of "Market disagreement · soon". Sell/Buy toggle, search, shared position,
  chart picker, older-week opt-in. Desktop table, mobile cards. Fails closed if `espn` is
  unavailable or the engine is not in its Indexed view.
- `pipelines/build_v2_page.py`: ships and loads `v2/targets.js` before `v2/v2.js`.
- No change to `curve-widget.js` or any engine file.
- `docs/v2-design-notes.md`: frame 03 = `59-1817`, frame 04 = `59-2567`, plus the tab's rules.
