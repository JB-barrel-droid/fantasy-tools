## Changes
- `ddf_value` is a first-class v2 series:
  - ★ symbol, brand orange, sorted first everywhere;
  - its own "DDF Value" group in the table;
  - chart line drawn last and heavier.
- First visit shows DDF Value plus the available as-published charts, ranked by DDF Value.
- Customize has a DDF Value section listing the engine's inputs:
  - draft until Done;
  - `setCompositeInputs` is called only when the inputs changed;

- Player values Reset also puts Rank by back to DDF Value (Jeremy, 2026-10-08).

- Copy:
  - the footer no longer says "no blended score";

  - the ⓘ indexing copy drops "Rankings within a chart don't change". That is false today (JEG-482).
