### Independent spot derivations

Used a separate arithmetic script (`/tmp/jeg1366-spot-derive.py`), not the pricing/weight/ES helpers: normal CDF via erf, binomial tail for unavailable starters, and the formula below. Upstream work lists, native values, replacement/starter lines, sigma and allocation probabilities are read from the pipeline. Thus this independently checks the ES parts, eight group sums, projection-only QB weights, non-QB scaling, budgets/rates and final blend; it does not independently refit sigma or player identity.

For each allocation: `v=max(0,x-waiver)`; `starter=availability*v*P(X>starter_line)`; `bench=availability*v*sum_d[P(Binomial(n,q)>=d)*P(lo_d<X<=hi_d)]`. Sum parts per group, normalize each source, replace the QB weights with the projection mean, scale the remaining weights by `(1-QBweight)/raw_nonQBweight`. Pie = `12 * (2+2+2+1+1) * 28 = 2688`; rate = `2688*W_group/group_parts`; player value = `starter*starter_rate + bench*bench_rate`; default DDF = mean of four chart values, then sum over allocation probabilities.
