  Analyst charts = mean of the CBS Sports, USA Today and FantasyPros values the engine lists (all three, else none);

  saved: a shared link's league, as v2 `applyLinkLeague`).
- `app/next/tradechart.js`: the table subtitle said "original published numbers"; the rows are league-priced engine
  values, so it now says "values priced for your league settings".
- `app/v2/v2.js` (small, additive): `SWAPPED_ROUTES["#compare-trade"] = "build.html"`; links with `mine`, `theirs`,
  `target` or `tc` stay on the classic view (codec, JEG-1538); a hashchange listener reads the link from the event's
