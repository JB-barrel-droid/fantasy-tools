## 2026-10-23 - A11y batch 2 (JEG-897, 899, 900, 901, 904)

Branch `fe/a11y-batch2`, PR "A11y batch 2", not merged. Visual design unchanged (one CSS line: the
combobox active result uses the existing hover tint). Source: audit
`audit-a11y-live-2026-10-22.md` (F2, F3, F4, F5, F7, F9).

### What changed
- JEG-897: rows (Player values, Trade targets table, expanded inner rows), phone cards and mover
  items go through `makeOpenable()`: `aria-haspopup=dialog`, `aria-describedby=#v2OpenHint`
  ("Opens player details. Press Enter or Space."), open on click, Enter and Space (only when the
  row itself is focused). `#v2Table` is `role=grid` and named by its heading. `#v2Chart` is
  `role=group` with `aria-roledescription=chart`; ArrowLeft/Right now also write the player,
  rank and "Enter for details" to a polite `#v2ChartSay` status line.
- JEG-899: `rove()` gives each table or list one tab stop (last-focused item). ArrowUp/Down/Home/End
  move between items, ArrowRight enters the value (math tooltip) cells, ArrowLeft/Escape returns.
  Value cells and waterfall steps are `tabindex=-1`: pointer focus and hover/tap tooltips unchanged.
  Player values: 200 stops for 50 rows -> 1.
- JEG-900: `TradeValueNameSearch.combobox(input, list)` (namesearch.js) wires Compare and Find a trade
  boxes: `role=combobox`, `aria-expanded`, `aria-autocomplete`, listbox/options, ArrowUp/Down with
  `aria-activedescendant`, Enter picks the highlighted result, polite "N players match" /
  "No players match". The old Enter-adds-first behaviour is unchanged when nothing is highlighted.
- JEG-901: chart dots are `role=img` with the above/below label; Start/Bench chip has an
  `aria-label` with its note; score, count, diff, "= consensus" notes and the legend items carry
  `aria-description` (title kept for mouse).
- JEG-904: Value-pie `th` get `scope=col`, every pie table has an `aria-label`; pie headings
  promoted h3 -> h2 and h4 -> h3; `#v2CTable` and `#v2CDealGrid` named via existing headings.

### Not done / judgement calls
- `li` cards and movers keep their list-item role (no `role=button`) because target cards contain
  source links, and a button would hide them. They get haspopup + description + roving focus instead.
- Score explanation was not moved into the info popover; it is `aria-description` for now.
- `aria-description` is ARIA 1.3: read by current Chrome, Safari and Firefox, older readers may skip it.
- Touch-only users still cannot see the title notes (no visible UI added; design unchanged).
