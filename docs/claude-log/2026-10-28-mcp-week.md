## 2026-10-28 - JEG-1179: get-values and the MCP tools price the site's week

Contract: get-values and every MCP tool that prices players default to the site's own week rule
(`ValueModel.weekState` from the published value-model.js, over the published week history), take an
optional `week` (N or N+1), answer a week with no published sources with a clear error, and return
`week`, `sources_included` and `missing_sources` with no carry-forward. read_state reads `wk=` from site
links. Fixes JEG-1157 (empty players during the gap). Code and draft PR only; nothing deployed.

What changed:
- `supabase/functions/get-values/pipeline.ts` (new): the engine input get-values builds, moved out of
  `index.ts` so the parity runner imports it instead of keeping a copy; plus the week view
  (curve-widget.js `resolveWeekView` / `computePipeline`, value_reference `Setting.week_view`): the
  served week of each source from `assets/history/index.json`, `weekState` over the DDF Value candidates,
  lagging sources left out, moved-on sources priced on their saved copy of the week
  (`assets/history/week-<N>.json`), "older" judged against the view's week. Calendar rule when the
  history is missing or from another build, as on the page.
- `get-values/index.ts`: loads the history index at cold start and a week document only when needed;
  `week` parameter; 400 `week_unavailable` with `weeks` and `default_week`; response `week`,
  `default_week`, `weeks`, `missing_sources`; answer cache keyed by week. `DDF_TODAY` env pins the clock
  for tests (the page's `TRADE_VALUE_TODAY`).
- Found and fixed on the way: get-values read divergence exclusions from `snapshot.divergence_exclusions`,
  but the build writes them at the bundle's top level (product-data.js reads them there), so an
  excluded source still fed DDF Value on the endpoint. Risk register: GAP-ENDPOINT-CALENDAR-WEEK.
- `supabase/functions/mcp/week.ts` (new) and `tools.ts`: `week` on every pricing tool's schema;
  `runTool` passes the asked week (or `wk=` from a pasted link; explicit wins) to get-values and adds the
  week fields, a "Week:" text line and `wk=` on the site link (only when a week was asked for).
  `mcp/index.ts`: `week` in the get-values query and cache keys; get-values' `week_unavailable` message
  becomes the tool error.
- `tests/_edge_pipeline_runner.cjs`: imports `pipeline.ts`; `--week`, `--history-index`, `--with-week`.
- Docs: `docs/values-endpoint.md` (Week section, MCP week bullet), `docs/get-values.openapi.yaml`.
