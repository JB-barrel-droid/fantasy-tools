Adjusted curves — pipeline stages

The _adjusted curves (FC Adjusted, USAT Adjusted, FP Adjusted, CBS Adjusted) flow through 5 stages: A1 Input data → A2 Fit executed → A3 Sections baked → A4 Synced to dist → A5 Live.
Each stage must run after the previous one. If any stage is stale, the curves pause on the live dashboard. Green requires the stage timestamp to be after the previous stage.

Methodology consistency

All as-published sources must use the same reindex method and anchor at each transformation step. A bad here means some combos were baked with a different method — an honest signal, not a hidden one.

VORP translation freshness

The as-published sources' chart values come from VORP-translated grains in Supabase, refreshed weekly (Wed 06:30 CT) and wired through by the chain's translate_via_vorp stage. Warn = a grain is older than the current NFL week (refresh or wiring pending). Bad = a combo is on reindex-fallback as its steady state — the quantile mapping JEG-64 replaced. Reads the provenance stamped into the fixture: what the chart serves, not what the pipeline claims.

Scale agreement — native vs reindexed vs anchor

For each as-published source × position: does the source's published shape track the ESPN anchor, and did our reindexing keep it there?
Agreement = both track. Genuine disagreement = the published numbers already differ from the anchor (needs Jeremy's accept-vs-fix call, not a pipeline fix). Indexation artifact = the published shape tracks the anchor but our reindex moved it — a pipeline defect. Band 0.80–1.25x, same as the chart's Chart Health scale-agreement check.

Cross-source agreement — systematic divergence detection

Every player present in all five sources, compared pairwise. Divergences > 25% among starters (value ≥ 20) are flagged — these are places the sources genuinely disagree, not artifacts of stale data or scale mismatch.
