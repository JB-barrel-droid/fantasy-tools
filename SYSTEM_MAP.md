# System Map

This file is the required root entrypoint for repo architecture. It is a map,
not a second architecture document.

## Authoritative Docs

- `README.md` owns operator commands, run order, and publish flow.
- `docs/architecture-current.md` owns the current product/runtime inventory.
- `docs/modular-pipeline.md` owns the four-stage pipeline shape.
- `docs/pipeline-rules.md` owns standing pipeline rules and source-of-truth
  contracts.
- `docs/risk-register.md` owns durable gaps, risks, unresolved questions, and
  follow-up actions.
- `docs/claude-log/` owns session-by-session evidence and verification notes
  (one file per PR/session; `docs/claude-log/README.md` has the format and
  rules; `docs/claude-log.md` is the frozen pre-2026-10-07 archive).

When these files conflict, prefer implementation plus the most specific
authority above, then update the stale document instead of carrying the conflict
forward in chat.

## Runtime Shape

```text
source data -> reference compute -> dashboard build -> frontend/site
```

- Source data lives under `data/raw/` when present and is treated as untrusted.
- Finished reference artifacts live under `data/fixtures/current/`.
- The static app source lives under `app/trade-value-chart/`.
- `dist/` is generated by `make sync` and is the deployable output.
- Regression tests live under `tests/`.

## Frontend Ownership

- `app/trade-value-chart/assets/value-model.js` owns shared value/role/allocation
  math used by both renderers.
- `app/trade-value-chart/assets/curve-widget.js` owns curve rendering,
  diagnostics, source toggles, roster controls, and chart interaction.
- `app/trade-value-chart/assets/comparison-dashboard.js` owns the player table,
  sortable columns, source comparison board, and news/context display.
- Both renderers must consume the same finished artifacts and shared value model;
  table/curve drift is a correctness bug.

## Current Known Boundaries

- Supabase is the production source store, but production writes require explicit
  user approval.
- Missing values remain missing; zeros must trace to a source-published zero.
- Adjusted source projects are live-derived from raw refs plus
  `adjustment-inputs.json`; they are not native upstream adjusted artifacts.
- The raw ESPN value-above-waivers series is separate from indexed trade value
  and must stay labeled as such.
