              How values work

              Three ways to read a player's value. Every one follows your league's settings.

              Your league

              — —

              Scoring, team count and roster decide where the waiver line sits and how many starters and bench players each position gets. Change them with Edit league; every view below updates.

              1. 1

                VORP vs waivers

                Dotted line

                Each source's value above a waiver-level player. Projections and published trade charts alike are translated the same way: start from the roster the publisher assumes (standard league settings unless its own materials say otherwise), read the positional weights its values imply for starters and bench, flex included, then measure each player against the waiver line.

                Each source keeps its own scale here, so these values are shown in their own panel and never compared with trade-value points.

                  Data Driven Adjustments

                  Solid line

                  Our value. Every source's value above waivers is re-weighted to Data Driven Football's weights by position and by starter or bench group, on the trade-value point scale for your league. ESPN, CBS rest-of-season and Razzball are priced this way straight from each publisher's own projections, never from another source's.

                  Use these to rank players and to weigh a trade, one source at a time.

                    Indexed

                    Dashed line

                    The published trade charts as their publishers rank them, indexed to match the value range of the other charts. The order and the shape are the publisher's own; only the scale moves.

                    This is what a manager trading off that chart expects. Where a chart pays more than our value, sell; where it pays less, buy.

                    Sources

                    Reading the numbers

                    • — means missing. A source that has no value for a player shows — with the reason, never zero.
                    • Zero is real. A value of zero means the player sits at or below that source's waiver line for your league.
                    • One source at a time. Sources are never blended into one score. Every comparison pairs one exact source and method with another.
                    • Older weeks are labeled. A source whose latest values are from an earlier week is marked as an older week, and only current-week sources are selected at first.
                    • Label and symbol. Each publisher keeps one color, one symbol and its name everywhere, so color is never the only cue.
