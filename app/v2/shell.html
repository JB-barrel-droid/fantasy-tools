                  VORP vs waivers

                  Raw value above a waiver-level player, on each source's own scale. Not comparable to the trade-value points above or to each other. Each row's steps are drawn on that source's own scale.

                  Each row uses one source only: the sum of what you receive minus the sum of what you give, in that source's values for your league. Rows are never combined into one score. The verdict reads one series, the one in Player values shown, and names the sources that see the trade the other way: where the sources disagree, that is the trade target. The steps in each row go from 0 down by each player you give (largest first), then up by each player you receive, and land on Receive − give; every row shares one scale. If a player has no value in a source, that row is incomplete and shows —, never zero. Open a row for the player-by-player arithmetic.

                        Read the evidence, then make the call.

                        • Methods can disagree. The same player can gain under Data Driven Adjustments and lose under Indexed.
                        • — means missing. A missing value is unavailable and shows — with the reason, never zero.
                        • Zero is real. A value of zero means the player sits at or below that source's waiver line for your league.
                        • Older weeks are opt-in. Only current-week sources are selected at first; an older week is labeled wherever it appears.
                        • Week changes compare one source. Risers and fallers compare the same source and method across two snapshots.
                        • Label and symbol. Each publisher keeps one color, one symbol and its name everywhere, so color is never the only cue.
