# JEG-114: Promotion Provenance Tracking

## Summary

Implemented provenance tracking to prevent a review generated after a fixture edit from rubber-stamping that edit.

## Problem

A review generated after a fixture edit can rubber-stamp that edit because:
- `review_candidate` hashes fixture natives and stores `fixture_native_sha256`
- `promote` verifies that hash matches current fixture natives
- But these hashes represent different objects (review stores what it saw, promote compares to current)
- If someone edits fixture, then runs review, then promotes - the hashes match incorrectly

## Solution

### Changes to `pipelines/review_comparison_candidate.py`

1. Added provenance tracking fields:
   - `fixture_native_before_sha256`: hash of fixture natives when review was created
   - `candidate_native_sha256`: hash of candidate's native values
   - `review_created_at`: ISO timestamp when review was generated
   - `native_change_classification`: classifies as `native_change`, `reindex_only`, or `native_new_source`

2. Added `native_change_classification` check that classifies the candidate:
   - `native_change`: candidate natives differ from fixture natives (actual update)
   - `reindex_only`: candidate natives identical to fixture natives (only reindex changed)
   - `native_new_source`: new source, no baseline for comparison

### Changes to `pipelines/promote_comparison_section.py`

1. Now requires provenance fields in review:
   - `fixture_native_before_sha256`
   - `candidate_native_sha256`
   - `review_created_at`
   - `native_change_classification`

2. Added native no-op detection:
   - Computes `candidate_native_hash` at promotion time
   - Compares to current fixture natives to detect `is_native_no_op`
   - Records `fixture_native_after_sha256` in promotion record

3. Legacy review handling:
   - For native-changing updates with missing provenance fields: fails closed
   - Requires re-running review with current tooling

4. Added provenance to promotion record:
   - `fixture_native_before_sha256`
   - `candidate_native_sha256`
   - `fixture_native_after_sha256`
   - `native_change_classification`
   - `is_native_no_op`
   - `provenance_warning`
   - `review_created_at`
