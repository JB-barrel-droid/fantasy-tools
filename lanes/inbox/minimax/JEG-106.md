# JEG-106: Parent Leg Lineage Chart Columns Stale for the 4 VORP-Adjusted Sources

## Summary

Fixed the parent lineage entries to not compare chart_value against itself and display a false green when the chart uses an adjusted leg.

## Problem

For the four sources with adjusted legs (cbs, fantasycalc, fantasypros, usatoday), the parent lineage was setting `chart_value = indexed_value` and comparing it to itself, always showing a green checkmark. However, the chart actually displays the adjusted leg's value, not the parent's indexed value.

## Solution Implemented (Option B)

- **Parent sources with adjusted legs**: Set `chart_value = None`, `chart_matches_indexed = None`, add `has_adjusted_leg = True` flag, add `adjusted_leg_pointer` field
- **Adjusted legs**: Compare chart value (adjusted) against parent's indexed value meaningfully (shows red when they differ)

This is option B from the proposal: N/A in parent chart column with a pointer to the adjusted leg.
