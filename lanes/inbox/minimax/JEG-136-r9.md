# JEG-136-r9: Scheduled Live Page Check from CI

## Summary

Implemented the scheduled live page check feature for the deployed trade value chart.

## Files Changed

1. **tests/rendered_gate/live.mjs** (NEW)
   - Remote runner for URL-based testing
   - CLI: `node live.mjs --url <url> --expected-build <tag> --out <path>`
   - Tests all 12 shapes (Standard/Half/Full x 8/10/12/14)
   - Detects: page errors, bad DDF pie, missing controls, build tag mismatch, navigation errors
   - Exports verdict() function for result evaluation

2. **tests/test_live_page_synthetic.py** (NEW)
   - Python unittest file for the live page gate
   - Tests verdict function logic, CLI parsing, output format
   - 20+ test cases covering all acceptance criteria
   - Integration tests marked with skip unless RUN_LIVE_INTEGRATION_TESTS=1

3. **.github/workflows/live-page-synthetic.yml** (NEW)
   - Runs daily at 06:00 UTC (1:00 AM CDT)
   - Also supports workflow_dispatch for manual runs
   - Downloads Playwright, reads build tag from dist, runs live.mjs
   - Uploads JSON artifact even on failure
   - Includes monitor bridge with freshness checking (36-hour threshold)

4. **lanes/inbox/minimax/JEG-136-r9.md** (NEW)
   - This summary file

## Scope Deviation

Per the brief: "Minimal extraction of shared browser checks is allowed only after reviewer agrees to this necessary deviation"

The implementation keeps live.mjs as a separate file rather than modifying gate.mjs to accept a URL. This:
- Preserves the existing local CLI behavior
- Avoids modification of the parent gate
- Is ready for reviewer approval to refactor shared logic
